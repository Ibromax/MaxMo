# MAXMO

MAXMO is a portfolio website for a Lagos-based photography and cinematography
studio. It showcases the studio's visual work, services, and journal.

**Live website:** [maxmopho.netlify.app](https://maxmopho.netlify.app/)

## Features

- Responsive portfolio with photography and film projects
- Project details with image galleries
- Studio services and journal entries
- Contact enquiry modal and mobile navigation
- Keyboard-friendly overlays and URL hash navigation

## Tech stack

- React 19 and TypeScript
- Vite
- Tailwind CSS 4

## Getting started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Build

```bash
npm run build
```

The production-ready site is generated in `dist/`.
